Kumm Android conserve son interface et utilise les horaires théoriques officiels CTS et SNCF enregistrés sur le téléphone. Le téléchargement initial nécessite Internet. Les horaires restent consultables hors connexion ; les fonds de carte, les adresses et les itinéraires piétons/vélo détaillés nécessitent Internet.

Les cheminements à pied locaux sont estimés ; l’accessibilité hors ligne reste à compléter avant validation de la parité fonctionnelle.

Les fonctions temps réel restent visibles avec la mention « Bientôt disponible ».

Les mises à jour GitHub sont facultatives : télécharger, reporter ou ignorer une version. Google Play reste le canal de mise à jour des installations Play.

Avant de publier ce brouillon, effectuer la recette Android décrite dans docs/ANDROID-AUTONOME.md. Ne pas supprimer la branche apk pendant la migration.
